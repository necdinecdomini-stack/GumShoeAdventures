SPECIAL INVESTIGATIONS — EDITABLE OFFLINE EDITION
===================================================

STARTING THE GAME
-----------------
1. Extract the complete ZIP archive.
2. Keep START_GAME.html, game.js, styles.css and the scenes folder together.
3. Double-click START_GAME.html.

No internet connection, account or local server is required.

EDITING OR REPLACING IMAGES
---------------------------
All scene artwork is stored separately in the scenes folder.

To replace an image without editing code:
1. Edit or create the replacement image.
2. Export it as WebP.
3. Give it exactly the same filename as the image being replaced.
4. Save it over the old file in the scenes folder.

The game will use the replacement the next time START_GAME.html is opened.
Keep the same aspect ratio where possible to avoid unexpected cropping.

OTHER MODIFICATIONS
-------------------
- styles.css contains the complete visual styling.
- game.js contains the game, intro text, cases and interactive functions.
- START_GAME.html is the small launcher page.

GITHUB PAGES
------------
For GitHub Pages, rename START_GAME.html to index.html and upload the complete
folder. Do not move or rename the scenes folder unless you also update the image
paths in game.js.

SAVED WORK
----------
Notes, highlights, timelines, progress and report drafts are stored in the
browser on the device being used. They are not sent anywhere. Clearing browser
site data may erase them.

PDF reports are produced locally and remain available offline.
