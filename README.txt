SONDERERMITTLUNGEN — OFFLINE-VERSION
====================================

1. Entpacke die gesamte ZIP-Datei in einen normalen Ordner.
2. Öffne den entpackten Ordner.
3. Doppelklicke auf START_GAME.html.

Eine Internetverbindung ist nicht erforderlich. Es muss nichts installiert
werden. Die Bilder, Fälle und das Spielprogramm befinden sich vollständig in
diesem Ordner.

Notizen, Markierungen, Zeitleisten und eingereichte Antworten werden vom
Browser lokal auf diesem Computer gespeichert. Wenn der Ordner in einem
anderen Browser oder auf einem anderen Computer geöffnet wird, beginnt dort
ein eigener Speicherstand.

Wichtig: Das Spiel nicht direkt innerhalb der ZIP-Vorschau öffnen. Zuerst die
gesamte ZIP-Datei entpacken, damit der Browser alle Bilder finden kann.
